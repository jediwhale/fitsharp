fitSharp
Release20261115
Features
  • Added the net11.0 and net11.0-windows targets for .NET 11.
  • Removed the net8.0 and net9.0 targets. The supported targets are .NET Framework 4.8 on Windows, .NET 10 and .NET 11.
  • The package keeps the compile references in lib and the runners in tools, one folder for each target.
  • Added a symbols package, so debuggers can load the sources of the libraries and the runners.
  • The libraries and the console runner build and pass the story suite on Linux from the same projects. The parallel Linux projects and solution are removed.
  • The package includes the README, the Common Public License and the GNU General Public License.

Upgrade Notes
  • The runners moved from lib to tools. A FitNesse command pattern that used lib/net10.0/Runner.dll now uses tools/net10.0/Runner.dll, and lib/net48/Runner.exe is now tools/net48/Runner.exe.
  • The Windows target folders are named after the Windows target framework version: net10.0-windows7.0 and net11.0-windows7.0 replace net10.0-windows.
  • There are no net8.0 or net9.0 assets. Applications that still target .NET 8 or .NET 9 use an earlier release.
  • The package version is the release date. Prereleases share the date of the stable release, so 2026.11.15-alpha.1 comes before 2026.11.15.
